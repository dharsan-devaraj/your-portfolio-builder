# Fix 404 Error - Quick Guide

## The Problem

Your repository is named `your-portfolio-builder`, but you're trying to access it at `/portfolio`. 

GitHub Pages URLs follow this pattern:
- Repository name: `your-portfolio-builder` → URL: `https://dharsan-devaraj.github.io/your-portfolio-builder`
- Repository name: `portfolio` → URL: `https://dharsan-devaraj.github.io/portfolio`

## Solution Options

### Option 1: Rename Repository to "portfolio" (Recommended)

1. Go to your repository: https://github.com/dharsan-devaraj/your-portfolio-builder
2. Click **Settings** (top menu)
3. Scroll down to **Repository name**
4. Change from `your-portfolio-builder` to `portfolio`
5. Click **Rename**
6. Update your local git remote:
   ```bash
   git remote set-url origin https://github.com/dharsan-devaraj/portfolio.git
   ```
7. Push your code again:
   ```bash
   git push origin main
   ```
8. Wait for GitHub Actions to deploy
9. Visit: https://dharsan-devaraj.github.io/portfolio

### Option 2: Use the Current Repository Name

If you want to keep `your-portfolio-builder` as the name:

1. The code is already configured to work with `your-portfolio-builder`
2. After deployment, visit: https://dharsan-devaraj.github.io/your-portfolio-builder
3. Update all your links to use this URL

## Verify Deployment

1. Go to **Actions** tab in your repository
2. Check if "Deploy to GitHub Pages" workflow ran successfully
3. If it failed, click on it to see the error
4. Go to **Settings** → **Pages**
5. You should see: "Your site is live at https://dharsan-devaraj.github.io/YOUR-REPO-NAME"

## Common Issues

### Workflow Not Running
- Make sure you pushed code to `main` branch
- Check if workflow file exists: `.github/workflows/deploy.yml`
- Make sure GitHub Actions is enabled in repository settings

### Still Getting 404
- Wait 2-5 minutes after deployment completes
- Clear browser cache (Ctrl+Shift+R or Cmd+Shift+R)
- Try incognito/private mode
- Check the exact repository name matches the URL

### Build Failing
- Check Actions tab for error messages
- Make sure `package.json` has all dependencies
- Verify Node.js version in workflow (currently set to 18)
